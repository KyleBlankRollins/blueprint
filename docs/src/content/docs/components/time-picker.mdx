The `bp-time-picker` component provides a dropdown interface for selecting times. It supports both 12-hour and 24-hour formats with configurable step intervals.

## Import

```javascript
import '@krollins/blueprint/time-picker';
```

### Help and error text

Use `helperText` for a hint under the control. Setting `errorMessage` marks it invalid: the message replaces the hint, is announced to screen readers, and the control gets the error color.

<ComponentPreview>
  <div class="component-preview-col">
    <bp-time-picker label="Start time" helperText="Your local time"></bp-time-picker>
    <bp-time-picker label="End time" errorMessage="The end time must be after the start time"></bp-time-picker>
  </div>
</ComponentPreview>

```html
<bp-time-picker
  label="Start time"
  helperText="Your local time"
></bp-time-picker>
<bp-time-picker
  label="End time"
  errorMessage="The end time must be after the start time"
></bp-time-picker>
```

## API Reference

### Properties

| Property       | Type                   | Default         | Description                                                                                                                                                    |
| -------------- | ---------------------- | --------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `value`        | `string`               | `''`            | Selected time (format: "HH:MM AM/PM" or "HH:MM")                                                                                                               |
| `name`         | `string`               | `''`            | Form field name for form submissions                                                                                                                           |
| `label`        | `string`               | `''`            | Visible label above the input                                                                                                                                  |
| `helperText`   | `string`               | `''`            | Helper text below the time picker, linked with `aria-describedby`                                                                                              |
| `errorMessage` | `string`               | `''`            | Error text. When set, the time picker is invalid: the message replaces the helper text, is announced (`role="alert"`), and the border turns to the error color |
| `placeholder`  | `string`               | `'Select time'` | Placeholder text shown when no time selected                                                                                                                   |
| `disabled`     | `boolean`              | `false`         | Disables the time picker                                                                                                                                       |
| `required`     | `boolean`              | `false`         | Marks the field as required for forms                                                                                                                          |
| `size`         | `'sm' \| 'md' \| 'lg'` | `'md'`          | Visual size of the time picker                                                                                                                                 |
| `format`       | `'12' \| '24'`         | `'12'`          | Time format (12-hour or 24-hour)                                                                                                                               |
| `step`         | `number`               | `15`            | Time interval in minutes (e.g., 15, 30, 60)                                                                                                                    |

### Events

| Event       | Detail                                                                     | Description                                                                                 |
| ----------- | -------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------- |
| `bp-change` | `{ value: string, hours: number, minutes: number, previousValue: string }` | Fired when time is selected. `value` is formatted string, `hours` and `minutes` are numbers |

### CSS Parts

| Part            | Description                       |
| --------------- | --------------------------------- |
| `label`         | The visible label                 |
| `input-wrapper` | Container wrapping input and icon |
| `input`         | The text input element            |
| `icon`          | The clock icon indicator          |
| `clear-button`  | The clear button (when value set) |
| `dropdown`      | The time options dropdown         |
| `time-option`   | Individual time option in list    |
| `helper-text`   | The helper text                   |
| `error-message` | The error message                 |

### Time Formats

**12-hour format:**

- Input: `9:30 AM`, `2:15 PM`, `12:00 AM`
- Displayed with AM/PM suffix

**24-hour format:**

- Input: `09:30`, `14:15`, `00:00`
- Displayed without suffix

### Keyboard Navigation

- **Arrow Down/Up**: Navigate through time options
- **Enter**: Select focused time
- **Escape**: Close dropdown
- **Tab**: Move to next element

### Accessibility

- Dropdown menu with proper ARIA attributes
- Keyboard navigation support
- Screen reader announces time selection
- `helperText` and `errorMessage` are linked to the input with `aria-describedby`; an error message sets `aria-invalid="true"` and is announced with `role="alert"`
